# Additional Theme Differentiation Matrix

## قاعدة القبول

لا يقبل أي ثيم إضافي إذا شارك ثيماً آخر في تكوين التنقل وLive TV وبنية البطاقة والمشغّل ونظام التركيز معاً. اختلاف اللون أو الخط أو الحافة وحده لا يحقق التمايز. تستخدم كل التجارب بيانات IPTV وViewModels والمشغّل نفسها، لكن طبقة العرض وUX تُنفذ بمكوّنات خاصة بالثيم.

## بوابات مراجعة إلزامية

| البوابة | شرط القبول |
| --- | --- |
| قبل التسجيل في Theme Selector | يملك الثيم App Shell وHome وLive TV وMovies وSeries وDetails وPlayer وFullscreen Player وSettings وLogin وSearch وFavorites وحالات dialog/loading/error خاصة به. |
| Live TV | تبقى القنوات قائمة عمودية؛ تتغير البنية البصرية وموقع العناصر وسلوك التنقل فقط. |
| المكوّنات | لا يعاد استخدام ChannelCard أو PlayerOverlay أو FocusModifier من ثيم آخر إذا أبقى التشابه البصري أو الوظيفي. |
| المقارنة | تقارن لقطات 1920×1080 للثيم الجديد مع كل الثيمات المسجلة؛ عند وجود تشابه في التركيب الأساسي يعاد التصميم. |
| المنطق | لا تستنسخ البيانات أو repositories أو ViewModels أو إعدادات المزود أو stream URLs بين الثيمات. |
