# Red Cinema UI Contract

Red Cinema is a **theatre programme**, not a colour adaptation of another theme. Its navigation uses numbered acts and ticket stubs; its home is a marquee plus a programme of screenings; its Live TV is a stage bounded by vertical ticket categories and vertical screening rows; its movie library is a cast list of showings rather than a poster shelf.

Its fullscreen player uses a centred reel transport, a perforated timeline, and a contiguous bottom ticket window. The remaining Red Cinema screens must follow this production vocabulary: vertical episode playbills, act-based search results, a saved-seat favourites ledger, a box-office settings surface, and a curtain-call provider/login form. The shared IPTV data, player, routes, and ViewModel contracts remain unchanged.
