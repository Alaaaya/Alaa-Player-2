# عقد تنفيذ ثيم Alaa

ثيم **Alaa** هو طبقة عرض قابلة للاختيار من الإعدادات، وليس تطبيقاً آخر أو بديلاً عن بنية Alaa Player 2. يعتمد التنفيذ على بيانات التطبيق الحقيقية فقط: المزودون، القنوات، الفئات، الأفلام، المسلسلات، المفضلة، سجل المشاهدة، التقدم، البحث، EPG والتشغيل. لا ينشئ الثيم قاعدة بيانات أو مستودعاً أو محرك تشغيل أو بيانات تجريبية مستقلة.

يحدد Figma التكوين، الهوية المرئية، القياسات، المسافات، الألوان، الخطوط، التدرجات، الزوايا، الحالات المركزة، وشكل Android TV. أما التطبيق فيحدد العناوين، الصور، الأوصاف، العدادات، التقدم، والبيانات المزودة فعلياً. لا تُثبت أسماء القنوات أو أعدادها أو الصور أو عناوين المحتوى الواردة في التصميم المرجعي.

عند اختيار Alaa، يجب أن تستخدم الطبقة المرئية الموحدة نظام ألوان ومسافات وأشكال وتركيز مركزي، وتنقل جانبي متوافق مع DPAD، وترويسة ديناميكية، وبطاقات قابلة لإعادة الاستخدام، وحالات تحميل/فراغ/خطأ متسقة. عند العودة إلى ثيم آخر، يعاد العرض السابق فوراً دون تغيير الحالة أو البيانات أو مسار العودة أو واجهات التشغيل.

## معايير القبول

| المجال | معيار التنفيذ |
|---|---|
| الصفحة الرئيسية | شريط جانبي، إجراءات علوية، ترويسة ديناميكية، فئات حية، متابعة المشاهدة، أقسام بيانات حقيقية، ومعلومات سفلية بنمط Alaa. |
| البيانات | كل الصور والعناوين والعدادات والتقدم من ViewModels وRepositories الحالية، مع صور بديلة آمنة عند غياب الفن. |
| التنقل | تركيز DPAD واضح ومتوقع بين الشريط والمحتوى والصفوف، مع تمرير العناصر المركزة إلى مجال الرؤية والمحافظة على Back الحالي. |
| الشاشات الأخرى | Live TV وMovies وSeries وFavorites وSearch وDetails وPlayer وSettings والحوار تستخدم طبقة العرض نفسها دون تبديل منطق العمل. |
| التبديل | يخزن الاختيار في نظام التفضيلات الحالي؛ لا يمس المزودين أو القوائم أو المفضلة أو السجل أو التقدم. |
| الجودة | لا ادعاء بمطابقة بكسلية قبل مقارنة لقطة Android TV عند 1920×1080 بالمرجع في Figma. |
