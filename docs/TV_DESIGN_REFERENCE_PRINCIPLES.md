# TV Design Reference Principles

## الغرض

تستخلص هذه الوثيقة مبادئ عامة لتصميم Android TV وSmart TV. لا تستخدم كقالب لنسخ أي واجهة أو علامة تجارية؛ بل كقيود تجربة مستخدم مشتركة عند ابتكار ثيمات Alaa Player الإضافية.

## مبادئ مشتركة لكل ثيم

| المبدأ | التطبيق في Alaa Player |
| --- | --- |
| اتجاه واضح | يملك كل اتجاه D-pad وظيفة قابلة للتنبؤ داخل المنطقة المركزة؛ لا توضع أدوات في زوايا يصعب الوصول إليها. |
| تركيز واحد مرئي | يوجد عنصر قابل للتركيز واحد واضح في كل لحظة، مع فرق بصري بين الحالات الافتراضية والمركزة والمضغوطة والمحددة. |
| محور تنظيمي | تستخدم الفئات والقوائم والمسارات محاور أفقية أو عمودية صريحة بدلاً من شبكات تنقل متداخلة ومعقدة. |
| رجوع متوقع | يعيد Back المستخدم إلى المقصد السابق أو منطقة التنقل المعروفة، ولا يخلق حلقات أو نوافذ تأكيد خروج غير لازمة. |
| قراءة من مسافة | تستعمل الشاشات طباعة كبيرة وتبايناً كافياً ومساحات وتركيزاً يمكن قراءته من بيئة تلفاز تقريبية. |
| تغذية راجعة | تعرض الحالات البطيئة loading واضحاً، وتظهر حالة Select/long press بصورة متسقة داخل كل ثيم. |

## قواعد Live TV المستخلصة

تظل القنوات قائمة عمودية في كل الثيمات. يسمح التصميم بتبديل موضع الفئات والمعاينة أو شكل اللوحات، لكن يحافظ على مسار D-pad منطقي بين الفئات والقنوات والمعاينة. تكون المعاينة غنية بالمعلومات عند توفرها من مصدر IPTV، ولا يجري اختراع أسماء قنوات أو برامج داخل الواجهة.

## لغة تركيز أصلية لكل ثيم

تعرّف كل تجربة مزيجاً خاصاً من scale وoutline وglow وتبدل لون السطح، لكن لا تتجاوز الحركة القصيرة الأداء المناسب للتلفاز. لا يعتمد أي ثيم على تركيز Android الافتراضي وحده، ولا ينسخ ألوان أو أشكال منتج خارجي.

## المراجع

1. [Android Developers — Navigation on TV](https://developer.android.com/design/ui/tv/guides/foundations/navigation-on-tv): مبدأ التنقل الفعال والقابل للتوقع عبر D-pad وBack، مع مسار واضح إلى كل عنصر قابل للتركيز.
2. [Android Developers — Focus system](https://developer.android.com/design/ui/tv/guides/styles/focus-system): حالات التركيز وإشارات scale والحدود والتوهج واللون والأسطح.
3. [Android Developers — Design for TV](https://developer.android.com/design/ui/tv): مراجع التخطيط والمكوّنات والتصميم الخاص ببيئات التلفاز.
4. [Samsung Smart TV — Design Principles](https://developer.samsung.com/smarttv/design/design-principles.html): مبادئ قابلية القراءة من مسافة، البساطة والوضوح والتغذية الراجعة للتلفاز.
