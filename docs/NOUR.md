# Nour

Select **Nour · نور** in appearance settings. Stored theme identifier: `nour`.
Existing themes are unchanged.

Nour supplies a floating pill navigation shell, crossfading featured artwork,
focus-aware movie and series libraries, detail screens, live channel browser,
guide, search keyboard/results, favorites, settings navigation and playback
overlays. Real combined-M3U source profiles receive Nour avatar cards in
provider settings; this does not add separate household user accounts.

The screenshot test uses seeded local artwork fixtures from
`/home/kit/shots-art`. These are UI previews, not evidence of provider login
or working media playback. Real-device playback and remote-control testing
remain necessary before a production release.
