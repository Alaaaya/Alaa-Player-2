## Integration requirements

Each theme must be registered only after it provides its own home, Live TV, EPG, movie and series browsing, category handling, details, seasons and episodes, search, favorites, recently watched, settings, login/provider setup, shell navigation, D-pad focus behavior, motion contract, player overlay, fullscreen player, and a unique bottom action bar. Shared domain models, navigation routes, persistence, provider parsing, and playback engine remain unchanged.
